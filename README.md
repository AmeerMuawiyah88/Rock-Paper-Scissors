# 😈 Stone Paper Scissors

A simple and interactive **Stone Paper Scissors Game** built with **Python and Tkinter**.

The game allows the player to choose between Stone, Paper, and Scissors while the computer randomly selects its choice. The winner is determined automatically and the score is updated after every round.

---

## 📌 About The Project

**Stone Paper Scissors** is a desktop-based game created using Python's built-in **Tkinter** library.

The player competes against the computer by choosing one of three options:

- 🪨 Stone
- 📄 Paper
- ✂️ Scissors

The computer randomly selects its choice, and the application determines whether the player wins, the computer wins, or the round is a draw.

The game also keeps track of both the player's and computer's scores.
